05

TECHNICAL RESEARCH PUBLICATION.

IJRTI // VOL. 11, ISSUE 9 // SEP 2026
PAPER ID: IJRTI26093 // ISSN: 2456-3315

Integrating Diffusion-Based Virtual Try-On into an E-Commerce Platform: A MERN-Stack Architecture Using IDM-VTON.

Co-Authors

Kishan Kushwaha, Krishna Thakur, Zaw Moe Hein, Hariom Paswan

Research Guide

Prof. Ankita Verma (Parul Institute of Engineering & Technology)

01 // Overview & Proposed Architecture

Addresses apparel e-commerce return rates caused by fit and appearance uncertainty. The paper traces the shift from GAN-based warping networks (VITON) to diffusion-based approaches and presents a proposed MERN-stack system architecture (not a fully validated production deployment) integrating a pretrained IDM-VTON model.

02 // Methodology & Stack

React storefront handles customer and garment image selection; Node.js and Express.js manage API orchestration and MongoDB persistence; Python and PyTorch execute IDM-VTON diffusion inference to synthesize garment-on-person previews.
